# 1. What is GraphQL?

GraphQL is a query language for APIs and a runtime for executing those queries with your existing data.

## Why GraphQL?
* **Exact Data Fetching:** Get exactly the data you need—no more, no less.
* **Solves Fetching Issues:** Eliminates over-fetching and under-fetching.
* **Strongly Typed:** Every API schema is strictly typed for predictability.
* **Single Endpoint:** Access all your data resources through a single endpoint (`/graphql`).
* **Powerful Developer Experience:** Features rich tooling, autocompletion, and self-documenting APIs.

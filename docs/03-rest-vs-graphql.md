# 3. REST vs GraphQL

| Feature | REST | GraphQL |
| :--- | :--- | :--- |
| **Endpoint** | Multiple Endpoints | Single Endpoint |
| **Data Fetching** | Over-fetching / Under-fetching | Exact Data (What you ask) |
| **Response Shape** | Fixed | Flexible |
| **Versioning** | URL Versioning (`/v1/`) | Not Required |
| **Requests** | Multiple Requests | Single Request |
| **Learning Curve** | Easy (CRUD) | Medium |
| **Best For** | Simple Resources | Complex Apps |

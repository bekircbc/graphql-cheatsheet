# 19. GraphQL Tools

## Explorer & Client Tools
* **Apollo Studio:** Cloud platform for schema registry, metrics, and API exploration.
* **GraphiQL / Altair:** Desktop and browser-based GraphQL query clients.
* **Postman / Insomnia:** REST and GraphQL supported API testing utilities.

## Engines & Gateways
* **Hasura:** Instant GraphQL engine over existing PostgreSQL databases.
